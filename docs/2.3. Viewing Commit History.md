# 2.3. Viewing Commit History  

Understanding how to view and interpret your project's commit history is essential when working with Git. This chapter will cover the `git log` command, commit hashes, and ways to track changes over time.  

---

## Viewing Commit History with `git log`  

The `git log` command is the primary tool for inspecting the history of commits in your repository. By default, it displays a list of commits in reverse chronological order, showing the most recent commit first.  

### Basic Usage  
To view the commit history, simply type:  
```bash
git log
```  
This will display:  
- **Commit Hash**: A unique identifier for each commit.  
- **Author**: The name and email of the person who made the commit.  
- **Date**: The timestamp of when the commit was made.  
- **Commit Message**: A short description of the changes in the commit.  

### Customizing `git log` Output  
You can customize the output of `git log` to make it more concise or to include specific details:  
- **One-line Summary**:  
  ```bash
  git log --oneline
  ```  
  Displays one line per commit, showing the abbreviated hash and commit message.  

- **Graph View**:  
  ```bash
  git log --oneline --graph
  ```  
  Visualizes the branch structure and merge history.  

- **Date Range**:  
  ```bash
  git log --since="2023-01-01" --until="2023-12-31"
  ```  
  Filters commits to those made within a specific date range.  

- **Filter by Author**:  
  ```bash
  git log --author="Author Name"
  ```  
  Shows commits made by a particular author.

## Understanding Commit Hashes  

Every commit in Git is identified by a unique **hash** (also known as a SHA-1 checksum). A commit hash is a 40-character string (e.g., `1a2b3c4d...`) that ensures the integrity of your repository.  

You can use these hashes to:  
- Reference specific commits for further inspection.  
- Revert or reset changes.  
- Compare versions of files.  

If you find the full hash cumbersome, Git allows the use of abbreviated hashes (e.g., the first 7-10 characters), as long as they uniquely identify a commit.  

To display only commit hashes, run:  
```bash
git log --format="%H"
```

## Viewing Changes Over Time  

To track how a file or project has evolved, you can view specific changes associated with each commit.  

### Show Changes with `git show`  
To see the changes introduced in a specific commit, use:  
```bash
git show <commit-hash>
```  
This command will display:  
- The commit details (author, date, and message).  
- The file modifications, including additions and deletions.  

### Compare Versions with `git diff`  
To see the differences between commits or between a commit and the working directory, use:  
- Changes in the working directory:  
  ```bash
  git diff
  ```  
- Changes between two commits:  
  ```bash
  git diff <commit-hash-1> <commit-hash-2>
  ```
