# 3.2. Merging Branches

## Fast-Forward Merges and 3-Way Merges
When changes in one branch are ready to be incorporated into another, they can be merged.
The command for merging is:

```bash
git merge <branch-name>
```

Git provides two primary merge methods:

### Fast-Forward Merge

```plaintext
main:    A---B
               \
feature:        C---D
```

If the branch being merged has not diverged from the target branch, Git simply advances the pointer:

```plaintext
main:    A---B---C---D
```

Example:
1. Start on the main branch:
   ```bash
   git switch main
   ```
2. Merge the feature branch:
   ```bash
   git merge feature/new-feature
   ```

#### 3-Way Merge

```plaintext
main:    A---B---C
               \
feature:        D---E
```

If both branches have diverged, Git performs a 3-way merge, combining changes and creating a new commit. This commit, called a merge commit, has two parents: the tip of both branches being merged.

```plaintext
main:    A---B---C---F
               \    /
feature:        D--E
```

This merge commit (`F`) preserves the history of changes from both branches and is necessary when changes on both sides must be reconciled.

### Resolving Merge Conflicts

Conflicts occur when changes in two branches affect the same part of a file. To resolve them:

1. Git marks conflicts in the affected files. Open these files in your editor to resolve the differences.
2. After resolving conflicts, stage the changes:
   ```bash
   git add <file>
   ```
3. Complete the merge:
   ```bash
   git commit
   ```

#### Example Conflict Resolution

Consider the following scenario:

- Branch `main` changes a line in `file.txt` to: `Line: Hello World!`
- Branch `feature` changes the same line to: `Line: Hi Universe!`

When merging `feature` into `main`, Git marks a conflict in `file.txt`:

```plaintext
<<<<<<< HEAD
Line: Hello World!
=======
Line: Hi Universe!
>>>>>>> feature
```

You resolve the conflict by editing the file to keep the desired changes:

```plaintext
Line: Hello World and Hi Universe!
```

Then, stage and commit the resolution.

### Abort a Merge

To cancel an ongoing merge and revert to the pre-merge state:

```bash
git merge --abort
```
