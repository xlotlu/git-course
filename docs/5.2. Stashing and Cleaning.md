# 5.2. Stashing and Cleaning

When working on a Git project, there are times when you may need to temporarily save changes or clean up your working directory without committing incomplete work. This is where stashing and cleaning come in handy.

---

## Stashing Changes for Later

Stashing allows you to save your changes and revert your working directory to a clean state. This is especially useful when you need to switch branches or work on something else without losing your progress.

### Creating a Stash

To stash changes:

```bash
git stash
```

This command saves your modified tracked files and restores the working directory to the last committed state. If you want to include untracked files:

```bash
git stash -u
```

Each stash is stored in a stack, and you can view the list of stashes with:

```bash
git stash list
```

### Naming a Stash

To make it easier to identify stashes, you can provide a name:

```bash
git stash save "work-in-progress: feature update"
```

---

## Applying and Dropping Stashes

### Applying a Stash

To reapply the most recent stash:

```bash
git stash apply
```

If you want to apply a specific stash from the list, use:

```bash
git stash apply stash@{index}
```

For example:

```bash
git stash apply stash@{0}
```

### Dropping a Stash

Once a stash is no longer needed, you can remove it:

```bash
git stash drop stash@{index}
```

To clear all stashes:

```bash
git stash clear
```

### Pop a Stash

To apply a stash and remove it in one step:

```bash
git stash pop
```

---

## Cleaning the Working Directory

Over time, your working directory may accumulate untracked files and directories that you no longer need. Git provides commands to clean up these files.

### Viewing Files to Be Cleaned

Before cleaning, you can preview the files that will be removed:

```bash
git clean -n
```

### Cleaning Untracked Files

To remove untracked files:

```bash
git clean -f
```

### Cleaning Untracked Directories

To remove untracked directories:

```bash
git clean -fd
```

### Cleaning Ignored Files

If you also want to remove files listed in `.gitignore`:

```bash
git clean -fx
```

---

## Using .gitignore

The `.gitignore` file tells Git which files or directories to ignore in a repository. This is particularly useful for preventing unnecessary files, such as logs or build artifacts, from being tracked.

### Creating a .gitignore File

To create a `.gitignore` file, add it to your repository's root directory:

```bash
touch .gitignore
```

### Adding Patterns to .gitignore

Specify files or directories to ignore using patterns. For example:

```
# Ignore all .log files
*.log

# Ignore the build directory
/build/

# Ignore a specific file
config.json
```

### Checking .gitignore Rules

To see if a file is ignored, use:

```bash
git check-ignore -v <file>
```
