# 1.3. Installing Git

## Installation on Windows, macOS, and Linux

### Installing Git on Windows
1. **Download Git**: Visit [Git Downloads Page for Windows](https://git-scm.com/downloads/win) and download the installer.
2. **Run the Installer**: Double-click the downloaded file and follow the installation wizard. You can choose the default options unless you have specific requirements.
3. **Verify Installation**: Open the Command Prompt and type `git --version`. If installed correctly, this will display the installed version of Git.

### Installing Git on macOS
1. **Use Homebrew (Recommended)**:
   - Install Homebrew if not already installed: `/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"`
   - Install Git: `brew install git`
2. **Verify Installation**:
   - Open the Terminal and type `git --version`.

Alternatively, macOS users can install Git using Xcode’s Command Line Tools by running `xcode-select --install` in the Terminal.

### Installing Git on Linux
1. **Use the Package Manager**:
   - **Ubuntu/Debian**: `sudo apt update && sudo apt install git`
   - **Fedora**: `sudo dnf install git`
   - **Arch**: `sudo pacman -S git`
2. **Verify Installation**:
   - Open the Terminal and type `git --version`.

## Basic Git Setup and Configuration  
After installing Git, set up your user information and preferences to ensure proper identification in commits.  

### Configuring User Information  
Run the following commands to configure your name and email address:  
- `git config set --global user.name "Your Name"`  
- `git config set --global user.email "your.email@example.com"`  

### Setting Default Editor  
Git uses a text editor for commit messages. Set your preferred editor with:  
- `git config set --global core.editor "editor-name"`  

For example, to set Visual Studio Code as the editor:  
- `git config set --global core.editor "code --wait"`  

### Git Configuration Levels  
Git configuration is managed at three levels:  
- **Local**: Specific to a single repository. Use `git config` with `--local` flag (or no flag, this is the default option).  
- **Global**: Applies to all repositories for the current user. Set with `--global`.  
- **System**: Applies to all users on the system. Set with `--system`. 

### Viewing Configuration  
To review your configuration, use:  
- `git config list`  

To review your configuration in a specific level, use the corresponding flag:
- `git config list --global`  


### Testing Git Configuration  
Run the following to check your setup:  
- `git config get user.name`  
- `git config get user.email`
