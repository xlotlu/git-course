# 4.2. Tagging

Tagging in Git allows you to mark specific points in your project’s history, such as release versions, for easy reference. Tags act as pointers to specific commits and can be used to label important milestones in your repository.

---

## Creating and Managing Tags

### Creating Tags

Git supports two types of tags: **lightweight tags** and **annotated tags**.

#### Lightweight Tags

A lightweight tag is a simple pointer to a specific commit. To create one:

```bash
git tag <tagname>
```

For example:

```bash
git tag v1.0
```

This creates a tag named `v1.0` that points to the current commit.

#### Annotated Tags

Annotated tags store additional metadata, such as the author’s name, the date, and a message. To create an annotated tag:

```bash
git tag -a <tagname> -m "<message>"
```

For example:

```bash
git tag -a v1.0 -m "First release"
```

This creates a tag named `v1.0` with the message “First release.”

### Listing Tags

To view all tags in your repository, use:

```bash
git tag
```

You can also filter tags based on a pattern:

```bash
git tag -l "v1.*"
```

This lists all tags starting with `v1.`.

### Tagging Specific Commits

You can tag a specific commit by providing its hash:

```bash
git tag <tagname> <commit-hash>
```

For example:

```bash
git tag v1.0 abc123
```

This creates a tag `v1.0` pointing to the commit with hash `abc123`.

---

## Sharing Tags with Remote Repositories

Tags are not automatically pushed to remote repositories. To share your tags, you need to push them explicitly.

### Pushing a Single Tag

To push a specific tag:

```bash
git push <remote> <tagname>
```

For example:

```bash
git push origin v1.0
```

### Pushing All Tags

To push all tags to the remote repository:

```bash
git push --tags
```

This ensures that all your tags are available on the remote.

---

## Deleting Tags

### Deleting a Local Tag

To delete a tag locally:

```bash
git tag -d <tagname>
```

For example:

```bash
git tag -d v1.0
```

### Deleting a Remote Tag

To delete a tag from the remote repository, you need to push a deletion request:

```bash
git push <remote> --delete <tagname>
```

For example:

```bash
git push origin --delete v1.0
```

---

## Checking Out Tags

While tags are not branches, you can check out a specific tag to view the project state at that point in time. This places your repository in a “detached HEAD” state.

```bash
git checkout <tagname>
```

For example:

```bash
git checkout v1.0
```

In this state, any changes you make will not be associated with a branch. To make changes, you should create a new branch:

```bash
git checkout -b <new-branch> <tagname>
```
